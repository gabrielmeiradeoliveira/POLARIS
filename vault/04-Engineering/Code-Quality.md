# Qualidade de Código

- Funções pequenas, coesas e de responsabilidade única.
- Tratamento explícito de erros, sem ocultar falhas.
- Sem código morto, comentários obsoletos ou mocks em código de produção.
- Revisão obrigatória conforme `.agents/workflows/review-code.md`.
