# Estratégia de Git

- Não realizar `git commit` ou `git push` sem autorização explícita do responsável pelo projeto.
- Nunca versionar segredos, credenciais, arquivos `.env` ou artefatos temporários.
- Manter `.gitignore` atualizado conforme a stack tecnológica for aprovada.

## Decisões Pendentes

- Convenção de nomes de branches e commits será formalizada antes do início da implementação de código de produto.
