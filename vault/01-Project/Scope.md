# Escopo do Projeto — POLARIS 2.0

## Dentro do Escopo (V2.x)

- Plataforma de análise estática de código local e determinística.
- Paridade funcional de referência com o SonarQube (a ser especificada no GOAL-001).
- Suporte oficial restrito às seguintes linguagens:
  - Python ([Python.md](../07-Languages/Python.md))
  - C# / .NET ([DotNet.md](../07-Languages/DotNet.md))
  - Java ([Java.md](../07-Languages/Java.md))
  - SQL ([SQL.md](../07-Languages/SQL.md))

## Fora do Escopo (V2.x)

- Inteligência artificial, SDKs de LLMs, serviços de inferência ou APIs de IA no produto (exclusivo da V3.0).
- Reaproveitamento ou importação automática de código da arquitetura anterior do POLARIS.
- Suporte a linguagens fora da lista oficial sem aprovação formal.
