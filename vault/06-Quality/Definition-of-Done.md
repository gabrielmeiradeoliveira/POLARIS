# Definition of Done (DoD)

Uma funcionalidade somente estará concluída quando todos os itens abaixo forem atendidos:

- [ ] Requisitos documentados.
- [ ] Critérios de aceitação definidos.
- [ ] Implementação realizada.
- [ ] Testes relevantes implementados.
- [ ] Testes executados.
- [ ] Integrações relevantes validadas.
- [ ] Comportamento real verificado.
- [ ] Requisitos de segurança aplicáveis atendidos.
- [ ] Evidências registradas.
- [ ] Documentação atualizada.
- [ ] Limitações registradas.
- [ ] Nenhuma falha impeditiva conhecida.
- [ ] Estado do projeto atualizado.

Caso algum requisito não seja atendido, registrar a pendência. Nunca declarar conclusão parcial como conclusão integral.
