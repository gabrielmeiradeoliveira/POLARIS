# Diretório `.agents/`

Este diretório contém os **procedimentos operacionais reutilizáveis** para agentes de desenvolvimento que atuam no POLARIS.

## Separação de Responsabilidades

- `AGENTS.md`: Contrato operacional obrigatório e hierarquia de instruções.
- `.agents/`: Regras de execução, workflows, papéis operacionais (roles) e templates.
- `vault/`: Fonte oficial de conhecimento, requisitos, decisões arquiteturais, políticas e histórico do projeto.

Este diretório não duplica o conteúdo do `vault/`; ele referencia o Vault e define como executar tarefas com segurança, rastreabilidade e qualidade.
