# Regra: Testes

1. Seguir a estratégia definida em `vault/06-Quality/Testing-Strategy.md`.
2. Não escolher frameworks de teste definitivos antes da aprovação da stack tecnológica.
3. Não desabilitar, pular ou enfraquecer testes para obter aprovação.
4. Mocks podem ser usados em testes unitários quando apropriado, mas nunca substituem testes de integração ou validação real.
5. Toda correção de bug deve incluir teste de regressão correspondente quando aplicável.
