# Regra: Dependências

1. Não instalar dependências desnecessárias.
2. Não instalar dependências de produção durante o GOAL-000.
3. Toda dependência relevante futura deve cumprir `vault/04-Engineering/Dependency-Policy.md` e `vault/05-Security/Dependency-Security.md`, documentando justificativa técnica, finalidade, licença, versão, alternativas, impacto, compatibilidade e estratégia de atualização.
4. Não adicionar bibliotecas apenas por conveniência.
