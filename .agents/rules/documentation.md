# Regra: Documentação

1. O diretório `vault/` é a fonte oficial de conhecimento do POLARIS.
2. Consultar o Vault antes de iniciar qualquer tarefa, seguindo a ordem obrigatória definida em `AGENTS.md`.
3. Todo documento relevante do Vault deve conter frontmatter YAML válido (`id`, `title`, `status`, `version`, `created`, `updated`, `owner`, `tags`) com datas reais (`YYYY-MM-DD`).
4. Estados permitidos para documentos: `draft`, `proposed`, `active`, `deprecated`, `archived`. Documentos `deprecated` ou `archived` não devem ser tratados como decisões vigentes.
5. Manter links internos compatíveis com Obsidian e utilizáveis em Markdown padrão, sem depender de plugins exclusivos.
6. Atualizar a documentação afetada após qualquer alteração e registrar decisões, problemas conhecidos e evidências.
7. Não criar arquivos vazios; todo documento deve ter conteúdo útil ou explicitar decisões pendentes.
